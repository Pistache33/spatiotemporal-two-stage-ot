# Data

This repository does **not** redistribute raw count matrices or large
intermediate arrays; only small result tables and figures are committed.

## MOSTA sections

We use three consecutive mouse-embryo sections from the MOSTA spatial
transcriptomics atlas
([https://db.cngb.org/stomics/mosta/](https://db.cngb.org/stomics/mosta/)):

| Section | Time point | Role |
|---|---|---|
| E9.5_E1S1 | E9.5 | Pair A source |
| E10.5_E2S1 | E10.5 | Pair A target / Pair C source |
| E11.5_E1S1 | E11.5 | Pair C target |

Two consecutive time-to-time transitions are studied:

- **Pair A**: E9.5_E1S1 → E10.5_E2S1
- **Pair C**: E10.5_E2S1 → E11.5_E1S1

## Feature representation: NBVAE-30

Every method in this repository operates on the same inputs, carried as
AnnData `obsm`/`obs` fields:

- `obsm["X_nbvae_30"]` — 30-dimensional NBVAE latents
- `obsm["spatial"]` — 2-D spatial coordinates
- `obs["annotation"]` — cell-type annotations

The NBVAE-30 latents are obtained with the following pipeline (scripts from
the original NBVAE/FGW preprocessing codebase):

1. **Build input** (`01_build_flatvi_input.py`) — select the strict 2,000
   highly-variable genes from raw counts.
2. **Train NBVAE** (`02_train_nbvae_flatvi.py`, invoked by
   `11_train_nbvae30.sh`) — a variational autoencoder with
   - model `nbvae`, latent dimension 30
   - 500 epochs, batch size 32, hidden dimension 256
   - learning rate 1e-3, KL warmup 500 epochs, validation fraction 0.2, seed 0
   - posterior-mean latent export
3. **Attach latents** (`08_attach_nbvae30.py`) — write the posterior-mean
   latents back into the section H5ADs as `obsm["X_nbvae_30"]`.

## Large intermediate outputs

Large arrays are excluded via `.gitignore` and regenerated by the code here:

- `hard_support.npz` — `src/stage1/run.py` (Stage-1 feasible set)
- `*_transport_sparse.npz`, `*_top1_target_index.npy` —
  `src/stage2/constrained_ot.py` (Stage-2 coupling)
- `transport.npy` (dense baselines) — `baselines/moscot/05_run_fgw_grid_point.py`
  and the SOCS caller
